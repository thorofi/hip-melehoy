What's included in this single file: Phase 1 – Calibration (10s): reads gamma baseline with live display, animated SVG ring, per-second beep + haptic Phase 2 – Running (10s): tracks deviation from baseline in real-time, shows live max deviation Results: color-coded badge (green/yellow/red), per-second bar chart, avg/max/baseline stats, share button iOS 13+ permission: DeviceOrientationEvent.requestPermission() called on button tap (required for Safari) Audio: Web Audio API chimes on start/end, soft beeps each second Vibration: navigator.vibrate() patterns at key moments No build step — just open the file in a mobile browser or serve it over HTTPS (required for sensor access on Android too) - Make it position must horizontal, since running belt mostly only can insert phone horizontally - Make the instruction to lift one leg, not running - Make history locally (if possible) and menu that can see the history (if user want to try left and right leg) Here's the fully updated index.html with all three changes — horizontal layout, single-leg lift test, and local history with comparison: Hip Drop Detector – RUNHOOD
